# Metrochem Quality Showcase

Build a beautiful, modern, premium corporate showcase website for **Metrochem Pvt Ltd**, a pharmaceutical and API manufacturing company.

This is a simple presentation website intended to showcase the company's identity, pharmaceutical manufacturing focus, quality-oriented approach, and industrial capabilities. It is primarily for visual presentation and brand credibility. Do not build a complicated application.

## 1. Design and visual direction

Create a sophisticated pharmaceutical manufacturing website inspired by premium international chemical, pharmaceutical, and life-sciences companies.

The design should look professional, credible, scientific, clean, and modern.

Use this color palette:
- Deep navy blue: #102A43
- Corporate blue: #1769AA
- Teal accent: #00A6A6
- White: #FFFFFF
- Light gray: #F4F7FA
- Dark text: #243746

Use Inter or a similar modern sans-serif font.

Use large, high-quality photographs of pharmaceutical manufacturing facilities, stainless-steel process equipment, chemical laboratories, scientists working in laboratories, and modern industrial environments.

Avoid cartoon graphics, hospital images, doctors treating patients, retail pharmacies, excessive gradients, and generic startup-style designs.

Use subtle animations, clean spacing, strong typography, and restrained scientific visual elements.

The final website should look like a professionally designed corporate website, not a generic AI-generated template.

## 2. Header

Create a clean, sticky navigation bar.

On the left, display a professional text-based logo:

METROCHEM
PHARMACEUTICAL MANUFACTURING

Use a subtle geometric or molecular icon beside the company name.

Navigation items:
- Home
- About
- Capabilities
- Quality
- Contact

Add a prominent blue button labeled "Contact Us".

The logo must link to the homepage. All navigation links must work correctly.

On mobile devices, use a responsive hamburger menu.

## 3. Homepage hero section

Create a visually striking, full-width hero section featuring a realistic pharmaceutical manufacturing facility or modern industrial laboratory.

Use a dark navy overlay on the image if necessary.

Main headline:

"Precision in Chemistry. Commitment to Quality."

Supporting text:

"Discover Metrochem's pharmaceutical manufacturing identity, technical focus, and commitment to responsible, quality-oriented operations."

Add two buttons:

Primary: "Explore Our Capabilities"

Secondary: "Contact Us"

The first button must scroll to the capabilities section. The second must navigate to the contact section.

Include a subtle scroll indicator.

The hero should be elegant and spacious, with strong visual impact and excellent text readability.

## 4. About section

Section heading:

"About Metrochem"

Subheading:

"Supporting Pharmaceutical Manufacturing Through Science and Precision"

Body text:

"Metrochem Pvt Ltd is presented as a pharmaceutical manufacturing business focused on the importance of scientific expertise, manufacturing discipline, and quality-oriented processes. This website introduces the company's industry focus, manufacturing identity, and commitment to professional business relationships."

Create a two-column layout with the text on the left and a high-quality industrial or laboratory image on the right.

Add three visual highlights:
- Scientific Approach
- Manufacturing Focus
- Quality-Oriented Mindset

Use minimalist line icons.

Do not invent the company's founding date, employee count, revenue, customer names, or manufacturing statistics.

## 5. Capabilities section

Section heading:

"Manufacturing Focus & Capabilities"

Display four attractive cards:

1. Pharmaceutical Manufacturing
   "A focus on the processes and technical disciplines associated with pharmaceutical manufacturing."

2. Active Pharmaceutical Ingredients
   "An introduction to the API manufacturing sector and its role in pharmaceutical production."

3. Process Development
   "The importance of process understanding, optimization, and manufacturing consistency."

4. Quality-Focused Operations
   "The role of documentation, process discipline, and quality-oriented practices in pharmaceutical manufacturing."

Use subtle icons, clean cards, and appropriate industrial imagery.

Treat these descriptions as general industry positioning, not verified claims about specific services offered by the company. Do not invent products, product specifications, or technical capabilities.

## 6. Quality section

Create a visually rich section with a laboratory or quality-control image.

Headline:

"Quality Is a Fundamental Priority"

Text:

"In pharmaceutical manufacturing, quality depends on scientific discipline, suitable process controls, reliable analytical methods, accurate documentation, and continuous improvement."

Display three simple features:
- Process Discipline
- Analytical Focus
- Continuous Improvement

Use a navy background with white text and restrained teal accents.

Do not display fake certifications, regulatory approvals, GMP badges, ISO logos, or unsupported compliance claims.

## 7. Manufacturing section

Headline:

"Designed Around Precision and Process Understanding"

Create a full-width image section showing realistic pharmaceutical process equipment or an industrial laboratory.

Include this text:

"Pharmaceutical manufacturing requires attention to process consistency, technical understanding, operational discipline, and responsible industrial practices."

Below the text, display a simple illustrative workflow:

Process Understanding → Manufacturing → Quality Evaluation → Continuous Improvement

Label this workflow as a general illustration rather than a verified description of the company's exact production process.

Use subtle animations and clean visual transitions.

## 8. Why Metrochem section

Create a professional section with four visual points:

- Scientific Thinking
- Quality-Oriented Approach
- Operational Discipline
- Professional Collaboration

Use a simple grid with line icons and short supporting descriptions.

Keep the language confident but factual. Do not invent testimonials, customer logos, awards, or claims of being the best manufacturer.

## 9. Contact section

Create a clean contact section with a dark navy background or a white background with blue accents.

Heading:

"Connect With Metrochem"

Supporting text:

"For business inquiries and further information, please get in touch with our team."

Include the following contact information only after verification:

Company name: Metrochem Pvt Ltd

Website: metrochempvt.works

Location: Visakhapatnam, Andhra Pradesh, India

Do not invent a telephone number, email address, or office address.

Create a simple visual contact form with:
- Name
- Company
- Email
- Subject
- Message

Since this is a showcase-only website, the form may be a frontend demonstration, but clearly indicate that it is not connected to a submission service until one is configured. Do not display a false "Message sent successfully" confirmation.

If a verified company email is supplied later, add a functional mailto link.

## 10. Footer

Create a sophisticated navy footer.

Include:
- Metrochem logo and company name
- Short company description
- Navigation links

- Copyright statement with the current year

Copyright:

"© [Current Year] Metrochem Pvt Ltd. All rights reserved."

Use the actual company name consistently and do not invent social media profiles.

## 11. Technical requirements

Build the website using Lovable's recommended React, TypeScript, and Tailwind CSS stack.

Requirements:
- Responsive desktop and mobile layouts
- Working navigation and anchor links
- Smooth scrolling
- Functional buttons
- Clean reusable components
- Proper typography and spacing
- Optimized images
- Semantic HTML
- Accessible contrast and keyboard focus
- Basic SEO metadata
- A custom favicon matching the logo
- No horizontal overflow
- No unnecessary dependencies
- No backend or database unless genuinely required

Do not build user authentication, dashboards, payment processing, shopping carts, complex APIs, or admin panels.

Use suitable stock images or generated visual assets that represent pharmaceutical manufacturing. Do not imply that illustrative photographs are actual images of Metrochem's facility.

## 12. Final execution instructions

Build the complete website in one generation.

Do not stop at a wireframe, plan, or static screenshot.

Implement the complete homepage with all the sections described above, ensure all navigation and buttons work, and make the final result visually polished.

Prioritize a premium corporate appearance, simple navigation, clean code, fast loading, and a professional pharmaceutical manufacturing identity.

The result should be a straightforward company showcase website that looks credible when visitors open metrochempvt.works.

Use tasteful design decisions independently wherever details are not specified. Avoid unnecessary complexity and focus on visual quality.
